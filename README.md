# Console Application "Auto Service" (Курсова робота)

Цей проект є консольним додатком, створеним мовою Java (Pure Java Core), як курсова робота з дисципліни "Об'єктно-орієнтоване програмування".

## 🚀 Функціонал
Програма має 2 режими роботи (ролі користувача):
1. **Клієнт** – взаємодіє з уже налаштованим (закодованим) автосервісом, вибирає відділ, замовляє послугу та отримує фінальний чек.
2. **Менеджер** – налаштовує новий автосервіс "з нуля", вводить його назву, кількість та назви відділів, після чого отримує звіт про створення.

## 🛠 Технології та Вимоги
- **Мова:** Java (виключно Java Core, без зовнішніх бібліотек, без GUI).
- **Колекції:** Використано `ArrayList` (збереження об'єктів та історії) та `HashMap` (прайс-листи).
- **Принципи ООП:**
  - **Інкапсуляція:** Приховані поля, доступ через гетери та сетери.
  - **Спадкування:** Клас `Auto_Service` успадковує `Service_Department`.
- **Безпека (Exception Handling):** Захист від введення некоректних даних завдяки обробці винятків `try-catch (InputMismatchException)` і правильній роботі з очищенням буфера `Scanner`.
- **Локалізація:** Увесь консольний інтерфейс та документація у коді виконані українською мовою.

## 📂 Структура Проекту
- `src/Main.java` - Весь вихідний код програми (розміщений в одному файлі для зручності завантаження згідно з вимогами).
- `docs/Architecture.md` - Детальний опис архітектури та UML-діаграма класів.
- `run.bat` - Скрипт для компіляції та запуску програми на ОС Windows.

## 💻 Як запустити
1. Переконайтесь, що у вас встановлено **Java JDK**.
2. Перейдіть до папки з проектом.
3. Двічі клікніть на файл `run.bat` для запуску або відкрийте термінал і виконайте `./run.bat`.
   - Альтернативно, скомпілюйте вручну:
     ```cmd
     javac -d bin src/Main.java
     java -cp bin Main
     ```
